НОВА ВЕРСІЯ: МІЙ БАНК + МОЯ КАСА
Це навчальний демонстраційний проєкт з віртуальними коштами. Не використовуй справжні банківські дані чи реальні гроші.

ЩО Є:
- реєстрація та вхід;
- стартовий демо-баланс 1000 грн;
- поповнення демо-балансу;
- переказ між користувачами за номером рахунку;
- каса магазину з товарами та QR-оплатою;
- після успішної оплати QR зникає з каси, кошик очищується;
- баланс магазину та склад;
- панель власника для товарів, цін і заявок продавців;
- ручна виплата зарплати;
- веб-версія банку, яку можна встановити як PWA на Android у підтримуваному браузері.

ЗАПУСК НА WINDOWS:
1. Встанови Node.js LTS з https://nodejs.org/
2. Розпакуй ZIP у папку.
3. Відкрий цю папку у Провіднику, клацни правою кнопкою на порожньому місці та відкрий PowerShell.
4. Виконай:
   npm.cmd install
   npm.cmd start
5. На комп'ютері відкрий http://localhost:3000
   Каса: http://localhost:3000/
   Банк: http://localhost:3000/bank.html
   Панель магазину: http://localhost:3000/admin.html

ПІДКЛЮЧЕННЯ ТЕЛЕФОНА:
- Телефон і комп'ютер мають бути в одній Wi-Fi мережі.
- На комп'ютері виконай ipconfig і знайди IPv4-адресу, наприклад 192.168.1.10.
- На телефоні відкрий http://АДРЕСА-КОМП'ЮТЕРА:3000/bank.html
- Для встановлення через Chrome: меню ⋮ -> Встановити застосунок / Додати на головний екран.
- Камера для QR зазвичай потребує HTTPS. Через звичайний HTTP за локальною IP-адресою браузер може заблокувати камеру. Для справжнього APK або HTTPS потрібне окреме налаштування.

ANDROID APK:
Цей ZIP містить повний сервер і вебзастосунок, готовий до тестування. Це ще НЕ зібраний APK. Для APK потрібне Android Studio та збірка Android-проєкту з WebView/Capacitor. Не встановлюй APK з невідомих джерел.

ВАЖЛИВО ПРО БЕЗПЕКУ:
- Це прототип для локальної демонстрації. Паролі зберігаються у простому JSON-файлі, панель власника не захищена входом.
- Не виставляй сервер у публічний інтернет і не використовуй для справжніх платежів.
- Дані зберігаються у data.json поруч із server.js.
